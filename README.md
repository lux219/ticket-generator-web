# Ticket Generator Web

Веб-приложение для выдачи экзаменационных билетов по данным из `students.xlsx` и `tickets.docx`.

## Возможности

- загрузка групп и студентов из Excel;
- разбор билетов из Word;
- закрепление первого случайного билета за студентом;
- регистрация повторных выдач;
- журнал и экспорт в `results.xlsx`;
- адаптивный интерфейс для компьютера и телефона.

## Запуск

Откройте `index.html` в браузере. Для локального сервера можно выполнить:

```bash
python -m http.server 4173
```

После этого откройте `http://localhost:4173`.

Для чтения Excel и Word используются библиотеки SheetJS и Mammoth, загружаемые через CDN.
